## 可能的疑问

#### 该段内容主要对复现过程中出现的一些疑问和问题做出了解释，请先阅读后续内容，若有疑问可以跳转到该标题处寻找答案。

1.**是不是模型的训练次数越多，训练的效果越好？**

​	不是，训练过程中训练误差会逐步下降，但是当训练次数过多时会造成过拟合，即模型的泛化能力会变弱

![image-20261008104519419](C:\Users\shi60\AppData\Roaming\Typora\typora-user-images\image-20261008104519419.png)

2.**如何避免过拟合：**

​	（本项目包含）早停机制、限制迭代上限、误差阈值、独立测试集评估

​	（其他）L2正则化（在代价函数中增加了对权重大小的惩罚）、Dropout(训练时随机关闭一部分神经元)、交叉验证、数据增强、增加数据、减少模型结构复杂度

3.**原项目中使用RTRL算法+ML算法来调整权重，为什么还要加入验证集寻找权重？**

RTRL和ML算法主要让模型与训练集的拟合程度越来越高，但是没有考虑是否会出现训练过度的情况，这时候使用验证集来增加早停机制能够让训练出来的模型具备泛化的能力。

4.**为什么使用Xavier+tanh效果比randn+tanh效果好**

randn是Numpy里边用来标准正态初始化的函数，抽取数据按照标准正态抽取。它的钟形曲线尾巴拖得够长，5% 的概率抽到绝对值 > 2。

网络中一共 139 个权重，按 5% 算就有 **7 个左右**一上来就是"超规格"的大权重，直接让对应的神经元饱和。Xavier 做的事就是把整条钟形曲线**压窄**（给randn加上0.39的缩放系数，（0.39的缩放系数是配合激活函数的特性而定的,因为 tanh'(0)=1，用一个神经元不从原点跑偏的方差反推出来））

## 一、论文内容与数据集

使用Numpy手写了一个人工神经网络（ANN），根据反应物及自由基相关特征，预测与 sp3 C-H 活化相关的氢原子转移（HAT）反应 Gibbs 活化能，未使用Transformer、Pytorch高层框架。

使用DFT计算获取甲氧基、三氟乙氧基、叔丁氧基和枯基氧基自由基的反应体系数据集。

**论文名：** Rapid and Accurate Estimation of Activation Free Energy in Hydrogen Atom Transfer-Based C−H Activation Reactions: From Empirical Model to Artificial Neural Networks

### 数据集

数据集包含 7 个输入特征：

- **BDFE_cat**（缩写错误：BDFE_rad）  
  自由基侧的键断裂自由能（H 提取自由基对应键的断裂自由能，反映反应自由基的热力学强度）。
- **BDFE_sub**  
  底物侧的键断裂自由能（被攻击的 C–H 键的断裂自由能）。
- **x_cat**  
  自由基侧的电负性（χ_rad）。
- **x_sub**  
  底物侧的电负性。
- **d**  
  不饱和性指示变量（邻近是否存在不饱和基团）。  
  `0` 表示饱和 C–H，`1` 表示不饱和 C–H。
- **Vbur_cat**  
  自由基侧埋藏体积（反映自由基在空间上对底物的拥挤程度）（Vbur_rad）。
- **Vbur_sub**  
  底物侧埋藏体积（表示底物侧的空间位阻特征）。

预测目标为 **gibbs**:反应的能垒

| 数据文件 | 样本数 | 用途 |
|---|---:|---|
| `train.csv`（四种自由基，每种60个样本） | 238 | 训练模型 |
| `test.csv`（新自由基） | 60 | 留出数据评估 |
| `selectivity.csv`（CH₃O-，新底物） | 15 | 选择性相关的额外评估 |
| `cumoexp.csv（`CumO- **实验数据** vs DFT数据）） | 45 | CumO 实验对照数据评估 |

## 三、模型建立与训练

### 模型结构

手写的全连接前馈神经网络。

结构为：

```text
[7, 6, 6, 6, 1]#7个特征，第一个隐藏层用了6个节点，第二隐藏层，第三隐藏层，输出层
```

输入层 - > 隐藏层 隐藏层 - > 隐藏层使用 `tanh` 激活函数（引入非线性）。

通过递归学习算法RTRL+ML算法实现训练权重的调整（**优化过程中加入了验证集验证**）

## 四、训练过程

```Python
#y=w1x+w2x+w3x+w4x+...w7x

导入训练集（239x8) -> 去掉列名分成特征矩阵（238x7)和目标矩阵（238x1）-> 定义神经网络，设置随机种子->根据随机种子给出的随机权重计算与导入的目标矩阵的误差->使用递归学习算法RTRL：更换权重 -> 计算误差 -> 计算误差的导数（J：d误差/d权重） ->使用Jacobian矩阵计算梯度g （J（i,j）:第j个权重变化时，第i个误差的变化率）-> 根据g调整权重

# k（复现次数）=500 次、E（均方误差）≤0.25、（early >= 5.0）误差连续5次不下滑终止模型训练
```

## 八、优化结果分析

- 训练集退步了（正常，验证集防过拟合就是牺牲一点训练精度换泛化）
- 测试集和选择性小幅提升 
- **CumO 反而退步了**  — Xavier 让模型走向了另一个局部最小值，对 CumO（x_cat=6）方向的泛化更差

**本质原因**：CumO 的催化剂（x_cat=6）和训练集中的催化剂分布不同，验证集是按训练集内的 x_cat 分层切的，没办法感知到 CumO 这种外部数据。Xavier 换了起点后，优化路径偏向了对训练集内部分布更友好的解，代价就是牺牲了 CumO 这个"角落"。

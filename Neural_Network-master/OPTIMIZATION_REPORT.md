## 第一阶段：工程优化（不改动模型结果）

### 1. `trainNN` — 随机种子参数化

**位置**: `trainNN(nn, P, Y, seed=64, val_ratio=0.2)`

| 改前 | 改后 |
|---|---|
| 种子硬编码为 `np.random.seed(64)` | 可通过参数 `seed` 控制，设为 `None` 则使用系统随机状态 |

**目的**: 允许用户控制结果可复现性，或关闭固定种子探索不同初始化效果。

---

### 2. `R` → `evaluate_model` — 函数语义化重命名

**位置**: `evaluate_model(name, Y, y_pred)`

| 改前 | 改后 |
|---|---|
| 函数名 `R`，无明确语义 | 重命名为 `evaluate_model`，参数新增 `name` 用于打印数据集名称 |

**目的**: 代码可读性提升，一眼知道这个函数是"评估模型"。

---

### 3. `saveNN` — 文件管理统一为 `with` 上下文管理器

**位置**: `saveNN(net, filename)`

| 改前 | 改后 |
|---|---|
| `file = open(...)` + `file.close()` | 统一使用 `with open(...) as file:` |

**目的**: 防止文件未正确关闭导致的资源泄漏，代码更安全。

---

### 4. 新增 `split_data` — 按催化剂分层划分验证集

**位置**: `split_data(P, Y, val_ratio=0.2, shuffle=True, seed=None)`

**核心逻辑**:
```python
# 按 x_cat（催化剂ID）分层
for cat in unique_cats:
    cat_indices = np.where(x_cat == cat)[0]
    # 每种催化剂单独 80/20 切分
    n_val = max(1, int(len(cat_indices) * val_ratio))
```

| 改前 | 改后 |
|---|---|
| 无数据划分功能 | 按催化剂分层：每种 `x_cat` 值内 80% 训练 / 20% 验证 |

**目的**: 确保每种催化剂在训练集和验证集中都有代表，避免特定催化剂完全缺失在某一侧。

## 第二阶段：算法优化（可能改变模型结果）

### 5. `w_Create` — Xavier 初始化替代 `randn`

**位置**: `w_Create(net)`

| 项目 | 改前 | 改后 |
|---|---|---|
| 输入权重 (IW) | `np.random.randn(layers[0], inputs)` | `np.random.randn(...) * √(2 / (inputs + layers[0]))` |
| 内部权重 (LW) | `np.random.randn(layers[m-1], layers[l-1])` | `np.random.randn(...) * √(2 / (layers[l-1] + layers[m-1]))` |
| 偏置 (b) | `np.random.randn(...)` | `np.random.randn(...) * 0.01` |
| 权重标准差 | 1.0（固定） | 0.39 ~ 0.53（自适应，取决于层大小） |

**原理**:

`randn N(0,1)` 约有 5% 权重落在 ±2 以外 → tanh(±2)≈0.964，梯度≈0.07 → 神经元初始即饱和，"出生即死亡"。

Xavier 将权重标准差缩放到 `√(2/(fan_in+fan_out))`，使加权输入 z 的方差 ≈ 1，全部落在 tanh 活跃区 [-2, 2] 内，每个神经元从一开始就有效参与学习。

| 层 | fan_in | fan_out | 改前 Std | 改后 Std |
|---|---|---|---|---|
| 输入→隐1 | 7 | 6 | 1.00 | 0.39 |
| 隐1→隐2 | 6 | 6 | 1.00 | 0.41 |
| 隐2→隐3 | 6 | 6 | 1.00 | 0.41 |
| 隐3→输出 | 6 | 1 | 1.00 | 0.53 |

**效果**: 139 个参数全部从第 1 轮开始有效参与学习，收敛更快、最终解更好。

### 6. `train_LM` — 验证集早停 + 最佳权重恢复

**位置**: `train_LM(..., val_tuple=None, val_patience=20)`

**新增参数**:
- `val_tuple`: 验证集 `(P_val, Y_val)` 元组，`None` 表示不使用验证集
- `val_patience`: 验证误差不降的最大容忍轮数（默认 20）

**核心逻辑**:

```
每轮迭代:
  E_val = calc_error(net, val_data)   # 用验证集算误差

  if E_val < best_val_E:              # 验证误差创新低
      best_w = net['w'].copy()        # 保存当前最佳权重
      val_no_improve = 0              # 重置忍耐计数
  else:
      val_no_improve += 1             # 不降则计数 +1

  if val_no_improve >= val_patience:  # 连续 N 轮不降
      break                            # 立即早停

训练结束:
  net['w'] = best_w                   # 恢复到验证误差最低时的权重
```

**关键设计**:
- 验证集**完全不参与** Jacobian 矩阵 / 梯度 / 权重更新计算
- 验证集仅用于 `calc_error` 计算误差，做早停和最佳权重选择的"旁观裁判"
- 验证集归一化使用训练集的 `normP/normY`，确保数据标准化一致

**效果**:
```
无验证集: 练到第 40 轮 (E_stop=0.25)，拿走第 40 轮权重
         验证误差 0.0945（已从最佳点 0.0827 回升 14%）
         训练误差一直降但测试泛化已经变差 = 过拟合

有验证集: 第 20 轮验证误差最低 (0.0827)
         继续练到第 55 轮 (E_stop=0.25)，训练结束自动恢复第 20 轮权重
         避免过拟合，测试泛化更好
```

## 性能对比

| 数据集 | 指标 | 老模型 (randn) | 新模型 (Xavier+验证集) | 变化 |
|---|---|---|---|---|
| **训练集** | RMSE | 0.6839 | 0.7802 | +14.1% |
| | R² | 0.9320 | 0.9115 | -2.2% |
| **测试集** | RMSE | 0.9882 | **0.9806** | **-0.8%** |
| | R² | 0.8712 | **0.8732** | **+0.2%** |
| **选择性** | MAE | 0.9207 | **0.8159** | **-11.4%** |
| | R² | 0.7198 | **0.7246** | **+0.7%** |
| **CumO** | RMSE | **0.8093** | 0.9514 | +17.6% |
| | R² | **0.6982** | 0.5828 | -16.5% |

**总结**:
- 测试集和选择性小幅提升（R² ↑），选择性 MAE 显著降低（-11.4%）
- 训练集精度下降（正常，验证集防过拟合以训练精度换泛化）
- CumO 实验数据退步：Xavier 改变了初始化和优化路径，模型更偏向训练集内分布，对外部 CumO 数据泛化反而变差
